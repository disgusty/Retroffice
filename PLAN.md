# План: поддержка doc, xls, ppt, rtf

Сейчас: odt/ods/odp/docx/xlsx/pptx/txt работают. doc/xls/ppt отклоняются, rtf показывается как сырой текст,
в выборе файлов эти типы не видны.

## Шаги
1. [x] `legacy/Cfb` — чтение контейнера OLE2 (Compound File Binary), в котором хранятся doc/xls/ppt.
2. [x] `legacy/OdfBuilder` — сборка ODT/ODS/ODP-пакета из простых данных (абзацы с жирным/курсивом/...,
       ячейки, слайды).
3. [x] Конвертеры:
   - [x] `RtfReader` — rtf → абзацы (кодировки \ansicpg/\fcharset, \u, жирный/курсив/подчёркнутый/зачёркнутый, размер, выравнивание).
   - [x] `DocReader` — Word 97–2003: таблица кусков (piece table), поля, форматирование символов (CHPX), выравнивание (PAPX); Word 95 — только текст.
   - [x] `XlsReader` — Excel 97–2003 (BIFF8) и 5.0/95 (BIFF5): листы, строки, числа, даты, логические, результаты формул.
   - [x] `PptReader` — PowerPoint 97–2003: слайды через persist directory, заголовок и текст.
4. [x] `DocLoader`: определять формат по содержимому, конвертировать во временный ODF и открывать как обычно;
       документ помечается как «конвертированный» — сохранение спрашивает новое место (оригинал не трогается).
       Зашифрованные doc/xls/ppt — понятное сообщение.
5. [x] Типы файлов: манифест (Открыть с помощью / Поделиться), системный выбор файлов, встроенный браузер, иконки.
6. [x] Тесты на ПК (JUnit): файлы, созданные LibreOffice из тестовых документов; результат проверяется
       повторным открытием в LibreOffice. Сборка + lint.

## Итог (2026-10-28)
Всё выполнено. Версия 1.1. Конвертированные документы сохраняются как новый ODT/ODS/ODP (оригинал не меняется).
Сборка/тесты из-за кириллического пути запускаются через junction с латинским путём (см. память проекта).
